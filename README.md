# Farmacia Cercana

Free static website (Spanish) that helps people find a pharmacy near them and manage their medicines.

## Tools (all client-side, no data leaves the browser)

1. Prescription renewal reminder — computes the renewal date from the last refill date and supply days.
2. Medicine expiry checker — days left until expiry, with expired / expiring-soon warnings.
3. Generic vs brand price comparison — savings per pack, per month and per year.
4. Pill schedule planner — evenly spaced daily dose times.
5. Pharmacy services checklist — 8 common pharmacy services to ask about.

Also includes a reference table of common over-the-counter medicine categories, 6 Spanish guides, and an FAQ.

All content is informational only and is not medical advice — consult a pharmacist or doctor.

Live at: https://farmaciacercana.github.io/
